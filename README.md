# 사이 — 이름 없이 나누는 마음

휴대폰을 중심으로 만든 익명 SNS 웹 앱입니다. 비회원도 전체 이야기를 읽을 수 있고, 이메일로 회원가입하면 익명 글·댓글, 공감, 이야기 저장을 이용할 수 있습니다. 이메일은 공개 글에 표시되지 않으며 비밀번호는 scrypt 해시로 저장합니다. 익명 이름은 글마다 달라집니다.

## 개발 실행

Node.js **24 이상**이 필요합니다. 기존 체크아웃에서 실행합니다.

```sh
npm ci
npm run dev
```

개발 화면은 `http://localhost:5173`, API는 `http://localhost:3000`에서 실행됩니다. 개발 서버는 모든 네트워크 인터페이스에 바인딩합니다. 휴대폰과 컴퓨터가 같은 네트워크에 있다면 휴대폰 브라우저에서 `http://컴퓨터의내부IP:5173`으로 접속할 수 있습니다. 방화벽에서 해당 포트 접근이 허용되어야 합니다. 클라우드 작업 공간의 내부 주소는 휴대폰에서 바로 접근할 수 없으므로 외부 사용에는 HTTPS 호스팅이 필요합니다.

개발 모드에는 ‘예시 이야기’라고 표시한 가상 글이 들어갑니다. 실제 사용자 게시물과 구분되며, 공감·댓글 수를 가짜로 채우지 않습니다. 예시가 필요 없다면 새 DB로 `SEED_DEMO=false npm run dev`를 실행합니다.

## 검증

```sh
npm test
npm run build
npm run test:ui
```

`npm test`는 임시 SQLite DB를 사용한 HTTP 통합 테스트입니다. `test:ui`는 모바일 Chromium 에뮬레이션과 데스크톱 브라우저 테스트입니다. 시스템 Chromium이 없으면 먼저 `npx playwright install chromium`을 실행하세요. 다른 실행 파일은 `CHROMIUM_PATH`로 지정할 수 있습니다. 브라우저 테스트 전에 `npm run build`가 필요합니다.

## 모바일 홈 화면에 추가

배포 후 HTTPS 주소로 접속하면 홈 화면에 추가해 앱처럼 열 수 있습니다.

- Android Chrome: 브라우저 메뉴의 **앱 설치** 또는 **홈 화면에 추가**.
- iPhone Safari: **공유 → 홈 화면에 추가**.

설치 메뉴의 이름과 제공 여부는 브라우저 버전에 따라 다를 수 있습니다. 일반 HTTP 내부 IP 접속은 모바일 화면 확인용이며, 앱 설치·서비스 워커는 HTTPS 환경에서 확인하세요. iPhone·Android의 실제 기기 검증은 별도로 필요합니다. 스토어에 등록하는 네이티브 앱이 아니라 모바일 웹/PWA입니다.

글·계정 데이터는 서버에 저장되므로 인터넷이 필요합니다. 서비스 워커는 공개된 오프라인 안내 화면만 저장하며 API 응답과 사용자 글을 캐시하지 않습니다. 오프라인 글 작성·자동 전송은 지원하지 않습니다.

## 운영 실행

```sh
npm ci
npm run build
NODE_ENV=production npm start
```

기본 포트는 `3000`입니다. 운영에서는 HTTPS 리버스 프록시 뒤에 두고, SQLite DB 디렉터리를 영구 볼륨에 보관하세요. 현재 구성은 단일 애플리케이션 인스턴스를 기준으로 합니다. 이 저장소 작업으로 외부 배포가 수행되지는 않습니다.

| 변수 | 기본값 / 용도 |
| --- | --- |
| `PORT` | `3000` — 운영 서버 포트 |
| `DB_PATH` | `data/app.sqlite` — SQLite 저장 파일 경로 |
| `NODE_ENV` | 운영 시 `production` 설정 |
| `SEED_DEMO` | 개발에서 기본 활성, 운영에서 기본 비활성. `false`로 신규 예시 생성을 끔 |
| `COOKIE_SECURE` | `true`로 HTTPS 전용 세션 쿠키. 운영 모드에서는 기본 적용 |
| `ALLOWED_ORIGINS` | 추가로 신뢰할 출처의 정확한 URL을 쉼표로 구분. 동일 출처 운영은 설정 불필요 |

로그인 시도 제한은 직접 연결한 IP를 기준으로 하므로 운영 프록시 환경에서는 프록시의 요청 제한 정책을 함께 설정해야 합니다. DB에는 계정과 게시물이 연결되어 저장됩니다. 여기서 익명은 다른 이용자에게 신원이 공개되지 않는다는 뜻입니다.
